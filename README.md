# DSAN 6750 Final Project

Research question: Did the Clandestine Detention Centers (CCDs) simply cluster around population centers or did they react to political ideology or something else?

Hypothesis: The CCDs were set up in locations with a higher concentration of individuals who opposed the military junta.
